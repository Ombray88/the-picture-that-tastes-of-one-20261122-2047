One picture of food, judged on how delicious it looks: a single glossy ripe mango, big in the frame, warm light, fresh and juicy — one ingredient you can taste at a glance. The program draws it procedurally in pure Python (standard library only, no network, no external assets) and writes it to `/output/entry.png`.

## Run it

